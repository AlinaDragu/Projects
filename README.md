# Projects

Web projects I built while learning front-end development, from small JavaScript exercises to full websites and an app with a Python back end.

Each project has its own folder and its own README with details and instructions.

## Websites

| Project | Description | Tech |
|---|---|---|
| [Portfolio Website](Portfolio/AlinaDragu-Website) | My personal portfolio: intro, work, about and contact | HTML, CSS/Sass, jQuery |
| [Pirate Nails](Portfolio/PirateNails-Website) | One-page site for a nail salon, with services and prices | HTML, CSS, jQuery |
| [Instagram Clone](Portfolio/Clone) | Copy of the Instagram feed with dark mode, stories and photo carousels | HTML, CSS, JavaScript |
| [Doctos Website](doctos%20site) | Landing page for Doctos, AI documentation software for dentists (in German) | HTML, CSS, JavaScript |
| [Styles Conference](styles%20conference) | Five-page conference site from the *Learn to Code HTML & CSS* course | HTML, CSS |

## Starters

- `calculator2/` – empty starter for a second calculator version (not started yet)
- `template/` – boilerplate CSS (`normalize.css`, `reset.css`, base `style.css`) to copy into new projects

## How to run

Everything except MonkeyFlow is front end only: open the project's `index.html` in your browser, or use the VS Code **Live Server** extension. MonkeyFlow also needs its Python server running, see [its README](Login/README.md).
