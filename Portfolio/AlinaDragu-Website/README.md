# Alina Dragu – Portfolio Website

My personal portfolio site, where I introduce myself and show my work to future clients and employers.

## Sections

The site is one page, and each section opens as a panel over a purple background:

- **Intro** – who I am and what I can build
- **Work** – my projects, with screenshots and links:
  - [Pirate Nails](PirateNails-Website/index.html) – website for a nail salon
  - [Instagram Clone](Clone/index.html) – a copy of the Instagram feed
- **About** – a bit about me as a software engineer
- **Contact** – contact form and links to Facebook, Instagram and GitHub

## Files

| | |
|---|---|
| `index.html` | The whole site |
| `assets/css/`, `assets/sass/` | Styles (the CSS is compiled from the Sass files) |
| `assets/js/` | jQuery and the scripts that open and close the panels |
| `images/` | Profile photo, backgrounds and project screenshots |
| `PirateNails-Website/`, `Clone/` | Copies of the two projects, so the portfolio links work on their own |

## How to run

Open `index.html` in your browser. The contact form is for show and doesn't send messages yet.
